## 什么是计算

无论任何语言，本质都是让计算机按其规定的流程运行。要充分地理解 C，对计算机本身必须有一定的了解。

我们这里只需将计算机抽象为这样一个东西，指令执行机和一片存储空间。

存储空间，是一堆存储单元的集合，然后每个存储单元都被赋予了一个正整数的编号，而这个正整数就是存储单元的 地址。

指令执行机，接受一条命令，对存储空间进行操作。例如：命令 C dataA addressB，就是将数据 A 放到 addressB。

值得注意的是，命令本身也在存储空间之中，所以命令和数据在存储空间中都只是一串数字。那什么决定了数据是数据，命令是命令呢？

是命令地址。指令执行机的运行，依靠一个特殊值 命令地址，指令执行机会读取命令地址所在的存储单元，解析这个值代表什么指令，如果是上面的命令C，就会读下一个存储单元（命令地址+1）和下下一个存储单元（命令地址+2），这就是 dataA 和 addressB。读取完毕，就会执行命令，将数据 A 放到 addressB。然后修改命令地址为命令地址+3，形成新的命令地址，进入下一个循环。

如上所述，程序就是存储空间中一片连续的存储单元中存储的数据，其形式就是一个接一个的命令。命令的数量往往倾向于够用，也就是在不影响性能的情况下，不随意添加可以被现有命令构造出来的命令，例如将一片地址 A，A+10，A+100，A+1000 都改为数据 B，这完全可以通过 4 个相同命令实现，也就是将数据放到地址 X 这个命令。

PS：值得注意的是，将 A～A+1000 都改为一个值的命令是有价值，但是为什么呢？

## 为什么要有C

如上所述，命令往往是有限且功能高度浓缩的，即通过多个命令的组合才能形成一个常用的逻辑。例如：构造如果 地址A的值 等于 B 就将 地址A的值 改为 C。

假设存储命令地址的存储单元的地址为 ADDR，然后我们选几个特殊的存储单元，地址分别为 R1，R2，R3，...

```
0: 将 B 复制进 R1 下
1: 比较 A 下与 R1 下的值，如果等于就写入 0 到 R2 下，否则写入 1 到 R2 下
2: 若 R2 下的值等于 1，则将 ADDR 的值改为 4，否则不动
3: 将 C 复制进 A 下
4: 停机
```

显然这样写，一是不直观，二是对编程者心智负担大，更容易导致出错。

所以，我们构建了 C 语言，将上述抽象为了

```c
if ( *A == B ){
  *A = C;
}
```

而 A 就是 C 语言中的 ***指针***，而指针就是**存储单元的地址**。

## 变量与类型

之前提及 命令 也是数据，命令地址也是存储在一个存储单元中。同样普通地址，例如上一节的 A，本身也是数据，也存储在一个存储单元中。

*A 代表 A 下的值，每次这么写是一件很麻烦的事情，而且我们往往也没必要知道 A ，我们只是单纯需要一个空间，至于这个空间在A还是R1，R2都无关紧要。

所以我们抽象出了 变量。我们说，我要一个空间 S1，S1 可能是 *A，也可能是 *R1，但都无所谓。我们只需要如下使用：

```C
S1 = S2 + S3;
```

将 S2 和 S3 的值加起来存入 S1。

如果我们要存的数比较大，空间放不下怎么办？我们就抽象出 **类型**，代表一组固定数量的挨在一起的存储单元。例如，我们定义 类型 T1，是 4 个存储单元，那 T1 S4 就是 S4 这个变量是由 4 个存储单元组成的。而 S4 等于 *D，而 D 就是这 4 个存储单元中，地址最小的那个单元的地址。
